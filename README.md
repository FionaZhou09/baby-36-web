# 宝贝三十六计 · 动物园网页试玩

对 [cocos56/Baby-s_36_Skills](https://github.com/cocos56/Baby-s_36_Skills) 的独立浏览器改编，**仅包含一个动物园关卡，非原游戏完整版**。适合家长陪同孩子练习安全选择。无账号、无聊天、无广告；无第三方脚本或数据收集。

## 游玩

点击开始，然后点击小路、人物或“走过去聊一聊”。也可按住左右按钮或使用键盘左右箭头。完成三次对话并走到集合点通关。选错会解释并允许重试，不扣分。支持设备中文朗读；部分浏览器缺少中文语音时可由家长读题。刷新页面会清空本轮进度。

## 本地启动和测试

```sh
python3 -m http.server 5180 --bind 127.0.0.1
node --test tests/*.test.js
```

打开 http://127.0.0.1:5180/ 。纯静态文件，无构建依赖。GitHub Pages 以 main 分支根目录发布，资源均使用相对路径。
