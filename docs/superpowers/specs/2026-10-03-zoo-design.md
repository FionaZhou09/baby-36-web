# 宝贝三十六计：动物园第一关

用户已同意先做单关卡 iPad 网页移植并发布 GitHub Pages。采用原项目 ZOO.png 和角色精灵，保留动物园探索与安全对话玩法；不尝试整套 Cocos 移植。相较于仿真旧引擎或仅做问答页，此方案保留走动与关卡闭环且适合静态托管。

## 体验
首页即游戏：标题、声音开关、家长说明、三枚进度印章、动物园场景、任务提示和开始按钮。开始后点地面移动，也支持左右方向按钮与键盘；遇到三个角色依次回答情境题。错误答案不惩罚、不结束游戏，而是解释并重试。正确答案获得一枚印章，三个挑战后走到右侧集合点通关。完成界面可重新开始。

## 内容
改编原 Data.json 的礼物诱惑、请孩子带路、带去吃东西三个动物园情境。使用明确的行动选项；强调先征求照顾自己的大人同意、陌生大人向工作人员求助、不单独跟人离开，不根据人物外表判断。中文朗读可关闭；无可用语音时仍可正常阅读和玩耍。

## 技术与可访问性
无依赖静态 HTML/CSS/ES modules；state.js 管理状态、题目和移动边界；main.js 管理 DOM、输入、朗读和渲染。UI 文本及按钮为真实 DOM；使用原画避免图形重绘。新增图像概念仅用于界面布局，原素材复用为有意偏离新生成游戏美术要求。桌面与 iPad 横竖屏均可用，手机缩小时角色仍有 44px 点击区。对话使用原生 dialog，键盘焦点受控；暂停/失焦停止移动，关闭朗读即停止当前语音。不开账号、不联网聊天、不收集输入。游戏进度仅本轮内存，刷新重来。

## 验收
单元测试覆盖三题完成、错误重试、不重复计分、输入边界、未通关不得结束、重开清零。浏览器验证全流程、触屏输入、横竖屏、家长面板、静音、资源404与脚本错误。GPL-3.0许可证及原作者归属保留，公开源码部署。
